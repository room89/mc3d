# Ошибка ширины и интервал из полосы плотности

Статус: кандидат проходит предварительную проверку; физическая приёмка
не завершена. Допуски сравнения физических вариантов не меняются.

## Завершённая проверка прежнего интервала

Матрица `shock-ensemble-centered-coverage-v2` завершила 2048 повторов:
16 сценариев по 128. Один повтор отклонён как неоднозначное выравнивание;
он включён в знаменатель как непокрытие. Итоговый статус —
`coverage_study_with_failures`, а не `passed`.

| Величина | Минимальное и максимальное покрытие по сценариям |
| --- | --- |
| Ширина 10–90% | 85,2–97,7% |
| Градиентная толщина, статистическая часть | 39,1–96,9% |
| Градиентная толщина, статистика плюс чувствительность обработки | 94,5–100% |
| Одновременная полоса плотности | 93,8–99,2% |

Это частоты на конечной выборке, не доказательство точного покрытия 95%.
[Компактный результат](shock-ensemble-centered-coverage-v2.json) содержит хеш
полного локального артефакта и параметры проверки.

## Установленные источники смещения

Без шума прежняя обработка даёт для Gompertz примерно +0,247% ошибки
градиентной толщины. Этот систематический сдвиг не обязан уменьшаться
с числом независимых повторений. Статистический интервал вокруг среднего
результата обработки нельзя трактовать как полный интервал ошибки относительно
истинной толщины. Чувствительность обработки остаётся обязательной частью бюджета.

Парный контроль использует одинаковые шум и сдвиги в двух ветвях:
известное истинное положение синтетического фронта и оценённое положение.
64 повтора на сценарий, по 12 групп в каждом, новые seed от 18000000.
Ни одного отказа. Значения ниже — процентные пункты относительной ошибки;
после ± указаны две стандартные ошибки среднего парного эффекта.

| Профиль и шум | Вклад выравнивания в ширину | Эффект замены кубической производной на пятую степень, при том же выбранном пике |
| --- | --- | --- |
| Logistic, 3%, пространственная корреляция 0,2 | −0,2377 ± 0,0111 | −0,0802 ± 0,0791 |
| Gompertz, 3%, пространственная корреляция 0,2 | −0,2030 ± 0,0094 | −0,1382 ± 0,0559 |
| Logistic, 1,5%, пространственно независимый шум | −0,0256 ± 0,0055 | −0,0792 ± 0,0562 |
| Gompertz, 1,5%, пространственно независимый шум | −0,0143 ± 0,0045 | −0,1394 ± 0,0384 |

Производная пятой степени уменьшает часть смещения, но увеличивает разброс.
Она используется только в диагностике, не заменяет основной оцениватель.
Известное положение синтетического фронта также не используется в обработке
физических данных. [Контрольные результаты](shock-ensemble-bias-controls.json).

## Новый интервал ширины

Опция `--width-band` добавляет границы ширины, полученные из существующей
одновременной полосы плотности. Если радиус полосы равен `u`, а `x(q)` —
координата пересечения монотонного оценённого профиля с уровнем `q`, то:

```text
w_lower = x(0.9 − u) − x(0.1 + u)
w_upper = x(0.9 + u) − x(0.1 − u)
```

Если полоса содержит монотонный истинный профиль, эти границы содержат его
ширину. Это условное свойство преобразования; оно не доказывает покрытие
исходной полосы и не устраняет погрешность пространственной интерполяции.
Радиус относительно точечной оценки берётся не меньше прежнего интервала
ширины. Неопределённость не ограничивается сверху допуском приёмки.
При недостаточном охвате уровней или `u >= 0.1` процедура отказывает.

Предварительная независимая проверка, seed от 19000000: четыре проблемных
сценария по 64 повтора. Для ширины — 256/256 покрытий; для градиента с обработкой
— 62–63/64; для плотности — 61–64/64. Отказов нет.
[Компактный результат](shock-width-band-screen.json). Это предварительная
проверка, не итоговая квалификация.

## Соответствие диапазону физического шума

Остатки физических окон после выравнивания измерены относительно среднего
своего seed, в области `abs(x) < 4`. Медиана стандартного отклонения составляет
0,0046–0,0136 у MC3D и 0,0084–0,0091 у SPARTA. Это диагностические остатки,
не идентифицированная модель шума. Они показывают, что проверки только 1,5%
и 3% не охватывают малошумный вариант G. Поэтому дополнительно проверяется
уровень 0,5%. [Оценки шума и корреляций](shock-window-noise.json).

## Малый шум: необходим отдельный бюджет интерполяции

Проверка с шумом 0,5%, seed от 20000000, дала 256/256 покрытий ширины,
но только 12,5–92,2% для плотности. У Gompertz без пространственной корреляции
покрытие плотности было 8/64. Поэтому одного изменения интервала ширины
недостаточно. [Результаты](shock-width-band-low-noise-screen.json).

В следующем кандидате опция `--interpolation-sensitivity` отдельно учитывает
разницу линейной и локальной кубической интерполяции по четырём точкам.
Сдвиги фронта и обучающие шаблоны не меняются. Для альтернативного среднего
профиля кубическая интерполяция применяется также при совмещении его уровня
50%. Экстраполяция запрещена. Основная точечная оценка остаётся прежней.

Максимальная разница двух средних профилей добавляется к статистической полосе
как чувствительность обработки, а не как статистический разброс. Аналогичная
разница производных добавляется к уже существующей чувствительности ширины
локального приближения. Для ширины полосы инвертируются раздельно со
статистическим и полным радиусом; дополнительная часть остаётся в поле
`processing_sensitivity`. Разница двух интерполяций — диагностическая оценка
погрешности, не универсальная строгая граница для любых функций.

Контроль без шума, fixture seed от 22000000, подтвердил покрытие плотности
после этого дополнения у обеих форм. Для Gompertz максимальная ошибка равна
0,00036164, полный радиус — 0,00036391. Шумная предварительная проверка
использует те же начальные seed и поэтому остаётся этапом выбора кандидата.

Шумная предварительная проверка этого полного бюджета завершена: 64 повтора
в каждом из четырёх сценариев с шумом 0,5% и 3%. Ширина покрыта в 256/256
повторов, градиент с обработкой — в 62–64/64, плотность — в 63–64/64.
Отказов нет. [Компактный результат](shock-interpolation-budget-screen.json).

Команда независимой полной проверки после фиксации кандидата (новые seed
и для данных, и для повторной выборки):

```sh
OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 python tools/calibrate_shock_ensemble.py \
  --output output/shock-interpolation-budget-validation.json --jobs 6 --replicates 128 \
  --matrix --center-profile --width-band --interpolation-sensitivity \
  --noise-levels .005 .015 .03 --seed-start 30000000
```

Следующий физический пилот должен сначала проверить C у MC3D и SPARTA на
независимых группах, а не повторять дорогие F/G без оценки необходимой точности.
Для подготовки такого пилота добавлен `shock_validation.py --variants C`.
Выбранные варианты записываются в отчёт; смена набора при `--resume` запрещена.
Выбор одного варианта не делает полную сходимость `passed`.

Для проверки половин серии калибратор поддерживает `--windows 32`.
Покрытие на 64 окнах не переносится на половины автоматически.
Обе независимые проверки запущены: по 24 сценария × 128 повторов.
Для половин используются seed от 32000000, четыре рабочих процесса и файл
`output/shock-interpolation-budget-halves-validation.json`. Алгоритм на время
этих проверок зафиксирован; результаты ещё не являются завершённой квалификацией.

## Подготовленный физический пилот

`tools/shock_independent_campaign.py` подготовил `output/shock-independent-c`:
исходная группа seed 123/456/789 используется только для чтения, ещё 11 групп
имеют seed 10003–10035 без повторений. Проверены исходные условия C, хеши двух
бинарных файлов, manifest MC3D и хеши файлов SPARTA. Новые solver-процессы
на этапе подготовки не запускались.

Контроллер записывает отдельные журналы групп, запрещает изменение протокола
при продолжении, ограничивает число одновременно выполняемых групп и при
прерывании останавливает запущенные им группы процессов. Незавершённые данные
сохраняются; исходный runner не перезаписывает прерванный результат молча.
Итог `execution_complete` относится только к выполнению выбранных расчётов.
Он не заменяет статистическую проверку, численную сходимость или эксперимент.

Команда выполнения после оценки независимой синтетической проверки:

```sh
python tools/shock_independent_campaign.py \
  --baseline output/shock-validation-restart/series \
  --binary output/shock-validation-restart/runtime/bin/MC3dSolver \
  --sparta-bin output/shock-validation-restart/runtime/sparta-build/src/spa_ \
  --output-dir output/shock-independent-c --variants C --jobs 6 \
  --load-mode full --resume
```

Проверено: 105 Python-тестов, подготовка всех 11 новых групп, короткий запуск
диагностики для 32 окон. Хеш исходного физического отчёта не изменился.

## Анализ после выполнения пилота

`tools/reanalyze_shock_campaign.py` требует 12 завершённых независимых групп
и завершённые синтетические матрицы для 64 и 32 окон с тем же кодом оценивателя.
Проверка наличия этих матриц не объявляет их покрытие достаточным автоматически:
минимальные частоты покрытия и число отказов переносятся в новый отчёт.

Анализатор заново восстанавливает MC3D-профили из сырых клеточных статистик,
проверяя реальные seed и хеши входов в manifest, нормированные конфигурации,
масштабы единиц и физические эталоны. По каждой группе отдельно вычисляются
полная серия, обе половины и попарно объединённые окна. Последние объединяются
в физических координатах до нового выравнивания, а не после него.
Сохраняются checkpoint по группе и варианту с хешами источников.

Средние плато, их изменение между половинами и удалённость границ проверяются
отдельно; число оконных выбросов остаётся в отчёте. Итоговый статус анализатора
`candidate_pilot_diagnostics_only` не заменяет итоговую физическую приёмку.

Интеграционная проверка на исходной группе восстановила градиентную толщину
MC3D C = 4,096279154828293 и SPARTA C = 4,099015778678496 с расхождением
менее `1e-12` относительно предыдущего пересчёта. Эта одна группа не выдаётся
за 12 независимых наблюдений.

```sh
python tools/reanalyze_shock_campaign.py output/shock-independent-c \
  --output output/shock-independent-c-analysis.json --jobs 2 \
  --coverage output/shock-interpolation-budget-validation.json \
  --half-coverage output/shock-interpolation-budget-halves-validation.json
```
