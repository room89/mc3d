# Согласованность экспериментальных источников

Статус на 2026-11-10: первоисточник Alsmeyer (1976) получен через Internet
Archive и проверен визуально. Экспериментальная приёмка остаётся незавершённой.
Ссылка, SHA-256 и ссылки на печатные страницы записаны в [experiment.json](experiment.json).
Прежние неудачные попытки загрузки сохранены как история получения источника.

В [диссертации T. E. Schwartzentruber (2007)](https://www.colorado.edu/lab/ngpdl/media/29#page=70),
раздел 4.1, печатная страница 51 (PDF 70), явно указано использование
экспериментального масштаба 1,098 мм, температуры 300 K и концентрации
1,6095 × 10²¹ м⁻³. PDF сохранён локально с хешем в [experiment.json](experiment.json).
Теперь значение масштаба проверено непосредственно по сноске на странице 499
первоисточника. Столкновительная длина свободного пробега текущей
VHS-модели не обязана совпадать с этим экспериментальным масштабом.

Сопоставлены извлечённые экспериментальные маркеры двух статей:
[arXiv:1909.02631, рис. 2(d)](https://arxiv.org/pdf/1909.02631#page=7)
и [arXiv:2411.13423, рис. 9(b)](https://arxiv.org/pdf/2411.13423#page=18).
Первая использует нормированную координату, вторая — метры. Для первой
применён фиксированный масштаб 1,098 мм из независимого источника.
Уровни определены линейной интерполяцией после монотонной регрессии точек.

| Воспроизведение | Ширина 10–90% |
| --- | --- |
| arXiv:1909.02631 × 1,098 мм | 4,31558 мм |
| arXiv:2411.13423, размерная ось | 4,39497 мм |

Относительное различие ширин составляет 1,83955%. Перенос начала координат
на уровень 50% этого различия не устраняет. Масштаб, который уравнял бы
ширины, составил бы 1,11820 мм; это только диагностическое число, которое
**не применяется** как подогнанный масштаб для сравнения с MC3D.

Таким образом, прежнее предварительное расхождение MC3D с размерным графиком
1,65% зависит от выбранного воспроизведения. Расхождение источников нельзя
автоматически назвать экспериментальной погрешностью, интервалом 95% или
новым допуском приёмки. Нужна проверка исходной нормировки и погрешности
оцифровки; арифметическое согласие с одной из кривых этого не заменяет.

## Что подтвердил первоисточник

На странице 499 приведена нормировка плотности `(rho-rho1)/(rho2-rho1)`
и координаты `x/lambda1`. Определение длины:
`lambda1 = (16/5) * sqrt(gamma/(2*pi)) * mu1/(rho1*a1)`.
Для Ar при 300 K и 50 mTorr табулированное значение равно 1,098 мм.
Это опорные условия масштаба; отдельный протокол опыта M=3,8 с такими
условиями не приведён. Указанный диапазон начальных давлений — 40–80 mTorr.

Автор оценивает точность нормированной плотности в ±1%, масштаба длины —
±1,3%, производной плотности и обратной толщины — примерно ±4%.
Этим оценкам не приписаны уровень доверия 95%, нормальное распределение
или независимость ошибок соседних точек. Погрешность оцифровки нужно
оценить дополнительно. На странице 501 разброс по минимум трём опытам
относится к полосам ошибок рис. 2, а не к независимым ошибкам точек профиля.
Опубликованные профили уже исправлены на электронику, кривизну фронта
и рост плотности за фронтом; повторять эти поправки нельзя.

На рис. 1(b), страница 500, эксперимент M=3,8 показан штриховой линией
рядом с близкими профилями других чисел Маха. Рис. 3 на странице 502
требует особой осторожности: квадратные маркеры M=3,8 соответствуют
**численному расчёту Bird**, эксперимент показан линией. Поэтому извлечение
квадратных маркеров этого рисунка не даст экспериментальные данные.

Следующий шаг — оцифровать экспериментальную линию M=3,8 с учётом толщины
штриха, разрешения и наложения кривых; сверить результат между рис. 1(b)
и 3 и с двумя вторичными воспроизведениями. Неоднозначные участки нельзя
заменять теоретической кривой. Затем перенести заявленные погрешности
и погрешность оцифровки в сравнение с расчётом без подгонки масштаба.

Воспроизводимая команда (параметр масштаба обязателен):

```sh
python tools/compare_shock_experiment_sources.py \
  --normalized output/alsmeyer-source/m38-secondary-vector-points.json \
  --dimensional output/alsmeyer-source/m38-secondary-dimensional-points.json \
  --reference-mean-free-path-m .001098 \
  --output output/alsmeyer-source/m38-secondary-source-comparison.json
```

Результат содержит хеши входных точек и инструмента; существующий результат
не перезаписывается. Проверки не допускают экстраполяции уровней за данные.
